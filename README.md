# Workshop — CAD Parts & Fixtures

SolidWorks models and laser-cut-ready DXF drawings for custom fixtures, jigs and fittings designed for a metal workshop. Most parts are sheet-metal designs that went from CAD to flat pattern to actual cut steel.

## Contents

| Folder | What's in it |
|---|---|
| `Alignment for metal cutter/` | Alignment jig for the metal cutter (two iterations: v1 and v2), with matching DXF profiles |
| `Carriage/` | Carriage wheel attachments in 3 mm steel — three design iterations, each with its sheet-metal flat pattern exported as DXF for laser cutting |
| `Table support/` | Support bracket for a workshop table |
| `Tool holder/` | Sheet-metal tool holder with connector piece, including flat patterns (v1 and v2) |
| `Letters/` | "WORKSHOP" signage — individual letters, back plate and full assembly |
| `Pick up tool sign/` | Sign for the tool pick-up point |

## File types

- **`.SLDPRT` / `.SLDASM`** — SolidWorks part and assembly files (source models)
- **`.DXF`** — 2D profiles and sheet-metal flat patterns, ready for laser or plasma cutting

## Notes

The versioned files (`_v2`, `_v3`) are kept on purpose — they show the design iterations as parts were test-fitted and adjusted. Material thickness and quantity are encoded in the file names where relevant (e.g. `steel3mm_x2`).
